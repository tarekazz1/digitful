# Digitful

Source for [digitful.ca](https://digitful.ca), built with Astro.

Install dependencies with `npm ci`; use `npm run dev` for local development and `npm run build` for a production build. GitHub Actions publishes the production site from `main`.

Project handoffs, task prompts, review records and working mockups are maintained in the [private internal repository](https://github.com/tarekazz1/digitful-internal). Agents should read [AGENTS.md](AGENTS.md) before working on this project.

The separate [preview repository](https://github.com/tarekazz1/digitful-preview) provides a guarded staging site for reviewing future changes. It is not required for production hosting.
