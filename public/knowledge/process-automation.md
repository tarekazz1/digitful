# Process Automation

Digitful connects tools already in use for lead follow-up, booking and reminders, data entry, reporting and internal handoffs. Work starts by mapping the workflow and prioritizing steps, then building connections with clear rules and documenting the system for the team.

Read the [service page](https://digitful.ca/automation/) or [discuss automation](https://digitful.ca/contact/?service=automation). Related: [Digitful](./digitful.md).
