# Local SEO Command Center

Only Digitful's owner operates the application. It runs on the owner's PC, where application data is stored. Reporting data supports reviews of search visibility, website engagement and advertising performance, and preparation of client reports. Reports are shared only with their intended clients.

Read the [application overview](https://digitful.ca/seo-command-center/) and [privacy policy](https://digitful.ca/seo-command-center/privacy/). Related: [SEO](./seo.md) and [Digitful](./digitful.md).
