# Digitful logo concepts — September 2026 retro/editorial direction

These files belong to the design-vision phase of the Digitful visual refresh. They are concept assets, not production-approved replacements for the current site logo yet.

## Intended concept asset names

- `digitful-wordmark-primary-dark-coral.png` — dark/ink primary wordmark with coral terminal dot.
- `digitful-wordmark-primary-light-coral.png` — cream/light primary wordmark with coral terminal dot.
- `digitful-wordmark-monochrome-dark.png` — dark/ink monochrome wordmark.
- `digitful-wordmark-monochrome-light.png` — cream/light monochrome wordmark.
- `digitful-wordmark-tagline-dark.png` — dark wordmark/tagline lockup concept.
- `digitful-mark-d-coral-dark.png` — standalone `d.` brand-mark concept.

## Status

- Direction: approved for further exploration, not yet production-final.
- Do not replace `public/assets/images/logo.svg` or `logo-light.svg` until the logo system and visual constitution are approved.
- Final production assets should ultimately be clean vector SVGs, with PNG/social/favicon exports derived from those masters.

Settle the visual constitution for the new Digitful identity, using the approved homepage mockup and this logo family as the main reference. After that, refine/select the final master wordmark and build the production asset pack.
