# Digitful Logo System

Status: **APPROVED — KEEP.**

The production logo is the concept-faithful lowercase wordmark:

**`digitful.`**

It is not derived from Barlow Condensed or any other runtime typeface. The approved SVG geometry is traced from the earlier approved concept artwork so the wider, rounder, softer proportions and custom letter character are preserved.

## Core colours

- Ink: `#191A1B`
- Paper / cream: `#F0E7D5`
- Coral terminal dot: `#E95849`

The coral dot is part of the primary mark, not optional decoration.

## Usage

### Full wordmark
Use the full `digitful.` wordmark for normal navigation, footer branding, page branding, presentations, and most public brand contexts.

On light surfaces, use the ink letters with coral dot. On dark surfaces, use the cream letters with coral dot.

### Standalone `d.`
Use the standalone mark only where the full wordmark is genuinely too small or too constrained, such as favicons, app icons, and compact avatars.

Do not substitute the standalone mark for the main navigation logo by default.

### Monochrome
Use monochrome versions only when colour reproduction is unavailable or inappropriate.

## Working size rules

- Full wordmark: minimum **104 CSS px wide**.
- Preferred navigation range: about **132–160 CSS px wide**.
- Standalone mark: minimum **20 CSS px**, with **24 px+** preferred.

These values may be tuned slightly during final responsive implementation if required for fit or accessibility, but the logo geometry must not be altered.

## Clear space

Let **D** equal the diameter of the coral terminal dot.

- Full wordmark: keep at least `1.5D` clear on all sides.
- Standalone mark: keep at least `1D` clear on all sides.

This is minimum clear space, not required layout padding.

## Do not

- stretch, skew, rotate, compress, or redraw the mark
- replace the approved lettering with Barlow Condensed or another font
- change the coral dot to an arbitrary accent colour
- add glow, blur, gradients, soft shadows, or glass effects
- outline the filled letterforms with a stroke
- place the primary colour mark on a surface with insufficient contrast
- detach, shrink, or scatter the terminal dot as a separate decorative device

## Relationship to site typography

Barlow Condensed 800 remains the approved site display/headline face. Inter remains the body/interface face. The logo is a separate custom vector mark and does not inherit either font.

## Approval history

Candidate 1, built directly from Barlow Condensed outlines, was rejected because it became too condensed and lost the approved concept's custom character.

Candidate 2 was traced from the approved concept artwork and received **KEEP** after preview review on desktop/mobile and light/dark panels.
