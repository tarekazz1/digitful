# Digitful Logo System

Status: **REJECTED — historical candidate record only.**

This file documents the first production-vector candidate for the refined `digitful.` logo. The candidate was rejected during preview review because deriving the mark directly from Barlow Condensed changed the character of the earlier approved concept too much.

Do **not** use this candidate as the basis for the next logo. Barlow Condensed remains approved for site display/headline typography only.

## Rejected candidate

The rejected candidate used the lowercase wordmark:

**`digitful.`**

Its letters were outlined from **Barlow Condensed ExtraBold / 800**, with a coral terminal period.

Colours used:
- Ink: `#191A1B`
- Paper / cream: `#F0E7D5`
- Coral terminal dot: `#E95849`

The SVG files are retained temporarily on `visual-refresh` as implementation history only. They are not approved production masters.

## Why it was rejected

Compared with the earlier approved concept PNGs, the Barlow-derived version became too condensed and typographic. It lost several brand-specific qualities from the approved direction:
- wider, rounder and softer letterforms
- more custom-looking proportions
- distinctive rounded `d`, `g` and `u` character
- a heavier, more geometric standalone `d.` mark
- a larger terminal coral dot that feels integral to the mark

The key correction is that **site display typography and logo lettering are separate decisions**. Barlow Condensed works for headings, but the logo does not need to use Barlow.
